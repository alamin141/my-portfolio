# Md. Al Amin Hossen — Portfolio

A responsive personal portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — main page
- `style.css` — styling and responsive layout
- `script.js` — menu, theme toggle and animations
- `assets/profile.jpg` — profile photo

## Deploy with Vercel
1. Create a GitHub repository, e.g. `my-portfolio`.
2. Upload all files and the `assets` folder.
3. In Vercel, choose **Add New → Project**.
4. Import the GitHub repository.
5. For this static site, leave the build settings at their defaults and click **Deploy**.

No build command is required.
